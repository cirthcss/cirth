# Attributions

This page records third-party visual assets used by the documentation. It is
the authoritative inventory for their source, owner, terms and the
maintainers' usage decision.

The names and marks belong to their respective owners. Their appearance here
identifies a documented integration. It does not imply affiliation,
certification or endorsement.

## Framework logos

The [Framework guides](/framework-guides) always print the project's name.
A logo is shown only when its data record includes a source and a documented
usage decision. Otherwise the guide uses text alone.

Files are served from this documentation, not hotlinked. They are kept in
the form supplied by the owner. A light-only asset with no official dark
variant is displayed on a light ground in dark mode instead of being
recoloured.

Some policies ask that a logo link to the owner's site or another named
address. On an individual guide page, the mark follows that requirement. In
the guide index, the complete card links to the Cirth guide and the image is
decorative. Any maintainers' decision that differs from the owner's normal
link request is stated in that project's note above.

Where a policy reserves the logo or requires permission that has not been
given, the integration is named with text and no substitute icon is drawn.
Open-source code licensing is not treated as a trademark license.

## Cirth lockup lettering

The Cirth lockup uses outlines derived from Onest, set at weight 650 with
softened corners. Onest is distributed under the
[SIL Open Font License 1.1](https://openfontlicense.org). Source: Onest 2.001
from the Google Fonts repository
([github.com/google/fonts](https://github.com/google/fonts/tree/main/ofl/onest),
`ofl/onest`), retrieved 2026-10-22.

Documentation serves the outlined lockup, not the font file. The license does
not require an acknowledgement for artwork made with the font
([OFL FAQ 1.1.2](https://openfontlicense.org/ofl-faq/)); this entry records
the source of the letterforms.

The entry does not make Onest the interface font or a dependency of Cirth.

## Documentation image

The home page's theme demonstration uses an imaginary relief-map cover. It
is an original illustration generated by the repository's
[`atlas-cover.html`](https://github.com/cirthcss/cirth/blob/master/docs/src/images/atlas-cover.html)
source and served as AVIF and WebP.

It is not a photograph or stock image. It contains no third-party logo or
interface and is licensed under Apache 2.0 with the repository.

## Maintaining this inventory

The records live in `docs/src/_data/frameworks.js`. Each one names the
owner, official source, terms reviewed, review date and any special
condition. The documentation build validates that a displayed file has the
required provenance fields and that a text-only entry explains the decision.

If an owner changes a policy or asks for a mark to be removed, open an
[issue](https://github.com/cirthcss/cirth/issues) with the project name and
the authoritative policy link.
